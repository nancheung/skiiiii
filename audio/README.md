# 音频替换

游戏默认用 Web Audio 实时合成所有声音，这个目录下不需要任何文件。想换成自己的录音或配乐时：

1. 把文件放进来（`audio/bgm.mp3`、`audio/sfx/land.mp3` 这样的路径）。
2. 在 `manifest.json` 的 `files` 里登记相对路径，例如：

   ```json
   { "files": ["bgm.mp3", "sfx/land.mp3", "sfx/wind.mp3"] }
   ```

文件名（去掉目录和扩展名）决定替换哪个声音。没登记或加载失败的，继续用合成音。浏览器能解码的格式都可以（mp3 / ogg / wav / m4a）。

| 文件名 | 类型 | 什么时候响 | 建议 |
| --- | --- | --- | --- |
| `bgm` | 循环 | 整趟背景音乐（替换后不再合成 BGM） | 2–4 分钟，首尾能无缝衔接 |
| `wind` | 循环 | 风声，音量随速度变化 | 3–10 秒白噪感 |
| `carve` | 循环 | 刻滑时刃切雪的嘶声 | 2–5 秒 |
| `skid` | 循环 | 推坡 / 侧滑的刮雪声 | 2–5 秒 |
| `powder` | 循环 | 粉雪里的闷响 | 2–5 秒 |
| `butter` | 循环 | 平花时板面擦雪 | 2–5 秒 |
| `pop` | 单次 | 起跳 | < 0.5 秒 |
| `land` | 单次 | 落地，音量随冲击变化 | < 1 秒 |
| `crash` | 单次 | 摔倒 | 1–2 秒 |
| `tree` | 单次 | 撞树 | < 1 秒 |
| `award` | 单次 | 动作得分 | < 1 秒 |
| `zone` | 单次 | 进入新区段（粉雪、蘑菇道、陡坡……） | 1 秒左右 |
| `finish` | 单次 | 冲过终点 | 2–3 秒 |

音量开关在开始卡片上（背景音乐 / 音效），游戏中按 `M` 或点右上角「声音」静音，设置保存在浏览器里。
